# S-108 — Reorganizar a tela do Grupo

**Marco:** E-ONB · **Deps:** S-107 · **Estimativa:** ≤3h, ≤8 arquivos

## Ler antes (somente estes)
- docs/spec/10-auth-family.md
- src/screens/Family/FamilyScreen.tsx, RecurringToggle.tsx

## Objetivo
Ordem de cima para baixo: botão **Ir para a lista**; lista de **membros colapsável**; botão **Categorias**; toggle **Não pode faltar** com explicação curta.

## Decisões (usuário, 2026-11-02)
- Membros (colapsável), Categorias e o toggle usam **a mesma linha/cartão visual** (mesmo componente-base, altura, ícone à esquerda, affordance à direita), mesmo sendo funções diferentes. Consistência visual é requisito.
- O convite continua na tela de entrar/criar grupo.

## Critérios de aceite
1. AC1 (componente): ordem dos blocos conforme acima; membros começam colapsados e expandem por toque.
2. AC2 (componente): as três linhas compartilham o mesmo componente-base.
3. AC3 (E2E): "Ir para a lista" navega à Lista; Categorias abre; toggle persiste (S-105 segue verde).
