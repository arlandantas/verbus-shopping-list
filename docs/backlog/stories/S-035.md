## Objetivo
Funções puras para o mês do ciclo e para ler/exibir preço em BRL.

## Critérios de aceite (cada um testável automaticamente)
1. AC1: unit `S-035 AC1`: `cycleOf(date)` usa a data local ("2026-11-01T00:30" local → "2026-11"); `formatCycle("2026-11")` → "novembro de 2026"; `isCycle` valida o regex da ADR-0012.
2. AC2: unit `S-035 AC2`: `parsePriceBRL` aceita "12,90", "12.90", "R$ 12,90", "1.234,50", "7" → 1290, 1290, 1290, 123450, 700; "" → null.
3. AC3: unit `S-035 AC3`: `parsePriceBRL` rejeita "abc", "-1", "12,999" e valores > 100 000,00 (resultado de erro tipado, sem exceção).
4. AC4: unit `S-035 AC4`: `formatBRL(1290)` → "R$ 12,90" (normalizar o espaço não separável no teste).
