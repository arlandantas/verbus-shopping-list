## Objetivo
Projeto pnpm com React 19 + Vite + TypeScript strict e Vitest rodando, na estrutura da ADR-0005.

## Critérios de aceite (cada um testável automaticamente)
1. AC1: `pnpm install --frozen-lockfile` e `pnpm build` terminam com código 0.
2. AC2: `pnpm typecheck` (`tsc --noEmit`, `strict: true`) termina com código 0.
3. AC3: `pnpm test` roda Vitest (jsdom + Testing Library) e um teste `S-001 AC3` verifica que `<App />` renderiza o título vindo de `src/strings/pt-BR.ts`.
4. AC4: alias `@/` resolve para `src/` no Vite, no TS e no Vitest (o teste do AC3 importa via `@/`).
5. AC5: `package.json` tem `"engines": { "node": ">=22" }` e `packageManager` com pnpm 11; versões das dependências fixadas (sem `^` em deps de runtime).

## Fora de escopo
- ESLint/Prettier/Tailwind (S-002), Firebase (S-003), PWA (S-005).

## Notas técnicas
- Arquivos esperados: `package.json`, `pnpm-lock.yaml`, `tsconfig.json`, `vite.config.ts`, `index.html` (`lang="pt-BR"`), `src/main.tsx`, `src/app/App.tsx`, `src/app/App.test.tsx`, `src/strings/pt-BR.ts`.
- Lockfile e `AGENTS.md` não contam no limite de 8 arquivos. Setup do Testing Library pode ir em `vite.config.ts` (`test.setupFiles` inline) para não passar do limite.
- Configurar Vitest já com `projects` (só `unit` por ora) para receber `rules`/`data` depois (ADR-0006).
- Atualizar a seção **Commands** do `AGENTS.md` com `pnpm install`, `pnpm dev`, `pnpm build`, `pnpm typecheck`, `pnpm test`.
