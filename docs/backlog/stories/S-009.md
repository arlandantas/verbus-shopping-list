## Objetivo
Funções tipadas em `src/data/` para criar perfil, criar família, entrar por código e observar usuário/família, testadas contra o emulador com as regras reais.

## Critérios de aceite (cada um testável automaticamente)
1. AC1: unit `S-009 AC1`: `generateInviteCode()` (em `src/domain/inviteCode.ts`) gera 8 chars do alfabeto da ADR-0003; `normalizeInviteCode(" abcd-2345 ")` → `"ABCD2345"`; `isValidInviteCode` rejeita `0`, `O`, `1`, `I`, `L`.
2. AC2: `pnpm test:data` (auth + firestore, regras carregadas): `ensureUserProfile(user)` cria `users/{uid}` uma vez e é idempotente.
3. AC3: `createFamily(name)` cria família, convite e `familyId` num só batch; retorna `{ familyId, inviteCode }`.
4. AC4: `joinFamilyByCode(code)` com código válido adiciona o usuário; código inexistente rejeita com erro tipado `InviteNotFound`; usuário já em família rejeita com `AlreadyInFamily`.
5. AC5: `watchUser(uid, cb)` e `watchFamily(id, cb)` usam `onSnapshot` e entregam objetos tipados (via `FirestoreDataConverter`); retornam função de unsubscribe.
