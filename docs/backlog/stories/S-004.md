# S-004 — Harness E2E com Playwright e emuladores

**Marco:** M0 · **Deps:** S-003 · **Estimativa:** ≤2h, ≤5 arquivos

## Ler antes (somente estes)
- docs/adr/0006-emulator-and-ci.md
- docs/rules/testing.md

## Objetivo
`pnpm test:e2e` sobe emuladores, serve o build em modo emulador e roda Playwright num viewport mobile.

## Critérios de aceite (cada um testável automaticamente)
1. AC1: `pnpm test:e2e` termina com código 0 sem rede externa nem credenciais.
2. AC2: teste `S-004 AC2`: em viewport mobile (Pixel 7, Chromium), a página `/` mostra o título de `pt-BR.ts`.
3. AC3: teste `S-004 AC3`: o app conecta ao emulador (a página expõe `data-emulator="true"` no `<html>` quando `VITE_USE_EMULATOR`, ou o teste verifica requisição a `localhost:9099`/`8080`).
4. AC4: helper `tests/e2e/support/emulator.ts` limpa Auth e Firestore do emulador entre testes (endpoints REST `DELETE /emulator/v1/projects/demo-verbus/...`).

## Fora de escopo
- Testes de PWA/offline (S-005). CI (S-006).

## Notas técnicas
- Arquivos: `playwright.config.ts`, `tests/e2e/smoke.spec.ts`, `tests/e2e/support/emulator.ts`, `package.json`.
- `webServer`: `pnpm build --mode development && pnpm vite preview --port 4173` (o build lê `.env.development`).
- Instalar só o Chromium (`playwright install chromium`).
- Adicionar `pnpm test:e2e` ao **Commands** do `AGENTS.md`.
