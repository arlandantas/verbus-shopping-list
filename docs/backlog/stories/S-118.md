# S-118 — Criador renomeia o grupo

**Marco:** E-UX · **Deps:** S-108 · **Estimativa:** ≤3h

## Ler antes (somente estes)
- docs/spec/10-auth-family.md
- docs/adr/0030-manual-pantry-and-group-rename.md
- docs/rules/firestore.md

## Objetivo
Só o criador vê "Renomear grupo" na tela do Grupo; o convite acompanha o nome.

## Critérios de aceite
1. AC1 (regras): criador altera só `name` (1–60); não criador, outro campo ou nome inválido negados.
2. AC2 (regras): membro atualiza `invites.familyName` só se igual ao nome novo do grupo; demais updates negados.
3. AC3 (dados): rename grava família e convite em um batch.
4. AC4 (componente/E2E): botão só para o criador; nome novo aparece no título.
