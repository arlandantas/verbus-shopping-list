## Objetivo
Cada membro publica o próprio nome na família e a UI obtém um mapa uid→nome para "quem marcou".

1. AC1: data `S-027 AC1`: `ensureMemberProfile(familyId, uid, displayName)` cria o doc; chamar de novo com o mesmo nome não grava (sem escrita extra).
2. AC2: data `S-027 AC2`: `watchMembers` entrega os nomes dos dois membros de uma família.
3. AC3: unit `S-027 AC3`: `memberLabel(uid, me, names)` devolve "você", o nome ou "alguém".
4. AC4: unit `S-027 AC4`: `FamilyProvider` chama `ensureMemberProfile` ao ficar `ready` (mock da camada de dados).
