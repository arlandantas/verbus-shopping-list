# S-071 — Campo de valor com máscara de centavos

**Marco:** UX2 · **Deps:** — · **Estimativa:** ≤2h, ≤4 arquivos

## Objetivo
Hoje digitar 1290 mostra "1290" e só formata no blur (lido como R$ 1.290,00). Esperado: máscara de centavos enquanto digita (1→"0,01", 12→"0,12", 1290→"12,90", 123456→"1.234,56").

## Critérios de aceite
1. AC1 (unit): `onChange` guarda só dígitos e exibe `formatBRL(Number(dígitos))` sem "R$" (prefixo continua no rótulo/adorno); `inputMode="numeric"`; apagar tudo limpa o campo (valor vazio = sem valor).
2. AC2 (unit): valor inicial em centavos (1290) exibe "12,90"; o valor entregue ao `onChange` externo é o texto formatado que `parsePrice` já entende (ou centavos, mantendo a API atual dos chamadores).
3. AC3 (unit): colar "R$ 12,90" resulta "12,90"; teto 10 000 000 centavos (limite das regras): dígitos extras são ignorados.
4. AC4 (E2E): no sheet "Editar item" e em Finalizar compra, digitar `1290` mostra "12,90" e salva 1290 centavos; testes antigos que digitavam "12,90" continuam verdes (adapte o `fill`).

## Notas técnicas
- Cursor sempre ao fim; usado em `ItemForm`, `CheckoutScreen`, `EditLineSheet`.
