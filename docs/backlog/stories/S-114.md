# S-114 — To-do: boas-vindas versionadas ("Novidades")

**Marco:** E-ONB · **Deps:** S-110 · **Estimativa:** a detalhar; pós-MVP, exige ADR

## Pedido (usuário, 2026-11-02)
Versionar a tela de boas-vindas. Quando uma funcionalidade nova sair, as boas-vindas são reescritas para usuários **novos**; usuários **antigos** veem só a novidade específica, uma vez.

## Notas
- Hoje o "já viu" é local por usuário e grupo (`welcomeSeen:{uid}:{groupId}`, ADR-0029): não tem versão. A ideia pede guardar a versão vista e um catálogo de passos com a versão em que cada um entrou.
- Decidir no ADR: onde guardar a versão (local x campo no usuário, para valer em vários aparelhos) e como distinguir usuário antigo (já viu qualquer versão) de novo.
- Não implementar agora.
