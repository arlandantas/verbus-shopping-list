# S-086 — Build de produção sem contas de teste nem painel de login rápido

**Marco:** SEC · **Deps:** S-085 · **Estimativa:** ≤2h, ≤5 arquivos

## Ler antes (somente estes)

## Objetivo
Provar automaticamente que o bundle publicado não carrega nada do S-050 (contas, senhas, painel) nem conecta a emuladores.

## Critérios de aceite (cada um testável automaticamente)
1. AC1: script `scripts/check-prod-bundle.mjs` faz `pnpm build` sem `VITE_USE_EMULATOR` e falha se algum arquivo de `dist/` contiver e-mails/senhas das contas de teste (lidos de `scripts/seed/`), o texto do painel de login rápido, `127.0.0.1:9099`, `127.0.0.1:8080` ou `connectFirestoreEmulator` com host.
2. AC2: o script sai 0 no estado atual (ou o código é ajustado para o painel ficar atrás de `import.meta.env.VITE_USE_EMULATOR` com import dinâmico eliminado no build).
3. AC3: build com `VITE_USE_EMULATOR=true` contém o painel (controle positivo, evita teste que passa vazio).
4. AC4: CI roda o script (job do `ci.yml`) e o deploy do Pages depende dele.
5. AC5: `pnpm check:bundle` documentado em AGENTS.md (uma linha em Commands).

## Fora de escopo
- Remover o seed ou o painel do modo emulador.

## Notas técnicas
- Ler os padrões proibidos da mesma fonte que o seed usa, para não divergir.
- Sourcemaps de produção, se houver, também entram na varredura.
